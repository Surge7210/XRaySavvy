# XRaySavvy auth email templates (Supabase → Authentication → Emails → Templates)

Paste the **Subject** and the **Body** for each template. Links use token_hash so email scanners can't use up the link before the student taps it.

## confirm-signup

Subject: `Confirm your XRaySavvy email`

Body: copy everything in [`confirm-signup.html`](confirm-signup.html) (tap **Raw**, then select all, copy).

## reset-password

Subject: `Reset your XRaySavvy password`

Body: copy everything in [`reset-password.html`](reset-password.html) (tap **Raw**, then select all, copy).

## magic-link

Subject: `Your XRaySavvy log-in link`

Body: copy everything in [`magic-link.html`](magic-link.html) (tap **Raw**, then select all, copy).

## change-email

Subject: `Confirm your new XRaySavvy email`

Body: copy everything in [`change-email.html`](change-email.html) (tap **Raw**, then select all, copy).
